# Демо-стенд для скриншотов

Пять SSH-серверов в Docker (web-01, web-02, db-01, staging, nas) и отдельный профиль vysh: ваши хосты, настройки и known_hosts не затрагиваются.

Нужны Docker Desktop (или Docker на Linux) и `ssh-keygen` (в Windows 10/11 уже есть).

```bat
tools\demo\start.bat
```

Скрипт генерирует ключ, поднимает контейнеры (порты 2201-2205 только на 127.0.0.1), пишет `hosts.json` и `settings.json` в `%TEMP%\vysh-demo` и запускает vysh с переменной `VYSH_CONFIG_DIR`, указывающей на эту папку. На Linux то же самое делает `tools/demo/start.sh`.

При первом подключении к каждому серверу vysh спросит про ключ сервера: это нормально, ключи сохранятся в демо-профиле.

## Скриншот для README

1. Размер окна около 1280×800, тема Catppuccin Mocha уже выбрана.
2. Откройте web-01 и db-01. В web-01 виден fastfetch, в db-01 запустите `htop`.
3. Вернитесь на вкладку web-01, подождите 3-4 секунды, чтобы в строке состояния появились CPU и сеть.
4. Снимок окна: `Win+Shift+S` → «Окно», сохранить как `docs\screenshot.png`.

## Остановить

```bat
tools\demo\stop.bat
```

Чтобы начать с чистого профиля, удалите `%TEMP%\vysh-demo`.
