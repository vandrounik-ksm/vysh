vysh объединяет в одном окне список серверов, терминал, файловый менеджер SFTP и средства диагностики подключения. Интерфейс построен на Material 3 и подстраивается под цвета системы или рабочего окружения.

## Возможности

### Хосты и вкладки
- Карточки серверов с группами, цветными метками и поиском.
- Быстрое подключение: строка вида `user@host:port` в поле поиска и Enter.
- Индикатор доступности хоста; для отдельных серверов его можно отключить.
- Вкладки с перетаскиванием, дублированием и индикацией состояния соединения.
- Массовые действия: несколько отмеченных хостов (Ctrl+клик) или целую группу можно подключить или удалить одной командой.

### Терминал
- Полноценный эмулятор: `htop`, `mc`, `vim`, 256 цветов и truecolor, поддержка мыши.
- Два режима копирования и вставки: как в Linux (выделение и средняя кнопка мыши) или сочетаниями `Ctrl+Shift+C` / `Ctrl+Shift+V`. Вставка по правому клику включается отдельно.
- Подтверждение перед вставкой нескольких строк, чтобы исключить случайный запуск команд.
- Выделение мышью с автопрокруткой; объём истории настраивается от 1 тыс. до 1 млн строк.
- Переподключение клавишей Enter после обрыва соединения.
- Нагрузка сервера в строке состояния: CPU, память, диск, сеть и время работы (для Linux-серверов).

### Подключение
- Аутентификация паролем, ключом OpenSSH (в том числе с парольной фразой) или стандартными ключами из `~/.ssh`.
- Пароль можно указать в карточке хоста или ввести при подключении, с сохранением или без.
- keyboard-interactive: PAM и одноразовые коды.
- Проверка ключа сервера с предупреждением при первом подключении и при смене ключа.
- Пароли хранятся в системном хранилище: DPAPI в Windows, Secret Service (gnome-keyring, KWallet) в Linux.

### SFTP
- Панель файлов рядом с терминалом, работающая поверх того же соединения.
- Загрузка файлов и папок перетаскиванием из проводника.
- Скачивание файлов и папок; очередь передач с прогрессом и скоростью.
- Открытие файла в локальном редакторе двойным кликом; после сохранения файл автоматически загружается обратно.
- Переименование, удаление, изменение прав доступа (`chmod`), создание папок.

### Диагностика
- Экран ошибки подключения с описанием причины и подробным журналом.
- Ping, трассировка маршрута и проверка порта непосредственно из приложения.

### Внешний вид
- Material 3 / Material You, светлая и тёмная темы, 9 акцентных цветов.
- Темы Catppuccin: Latte, Frappé, Macchiato, Mocha и 14 акцентов (Windows и Linux).
- Цвета системы: акцент Windows или xdg-desktop-portal (GNOME, KDE).
- Цвета из конфигураций рабочего окружения: caelestia и pywal определяются автоматически, matugen и wallust подключаются через готовые шаблоны. При смене обоев цвета обновляются без перезапуска, подробнее в [docs/THEMES.md](docs/THEMES.md).
- Тема терминала следует акценту приложения, а при использовании цветов окружения берёт их 16-цветную палитру.
- Собственный заголовок окна с вкладками в Windows, GNOME и KDE; в тайловых оконных менеджерах (Hyprland, sway, i3) используется обычное окно без декораций.
- Экономное потребление ресурсов: отрисовка через Skia (в 2-3 раза меньше памяти, чем с Impeller), фоновые проверки выполняются только для видимых элементов; все параметры настраиваются.
- Окно открывается с прежними размером и положением (в Wayland положение определяет композитор).
- Интерфейс на русском и английском языках.

### Android
- Цвета и значок приложения из системной палитры Monet (Material You).
- Панель клавиш над экранной клавиатурой: Esc, Ctrl, Alt, Tab, Home/End, PgUp/PgDn, часто используемые сочетания и быстрый доступ к SFTP.
- Контекстное меню выделения в терминале: копировать, вставить, вырезать, выделить всё, поделиться.
- Сессии сохраняются при сворачивании приложения: активные соединения удерживает системное уведомление.
- Файлы, скачанные по SFTP, сохраняются в общую папку «Загрузки» без запроса дополнительных разрешений.

## Установка

### Windows
1. Скачайте `vysh-<версия>-windows-x64.zip` со страницы [релизов](../../releases/latest).
2. Распакуйте архив в любую папку и запустите `vysh.exe`.

> При первом запуске Windows SmartScreen может показать предупреждение о неизвестном издателе.
> Для запуска нажмите «Подробнее», затем «Выполнить в любом случае».

### Arch Linux
PKGBUILD прикладывается к каждому релизу; пакет устанавливается через pacman:
```sh
mkdir vysh && cd vysh
curl -LO https://github.com/vyto4ka/vysh/releases/latest/download/PKGBUILD
makepkg -si
```
Для обновления выполните те же команды в пустой папке. Удаление: `sudo pacman -R vysh-bin`.

Программа устанавливается в `/opt/vysh`, запускается командой `vysh` и появляется в меню приложений. Для хранения паролей требуется Secret Service: `gnome-keyring`, KWallet или KeePassXC.

### Другие дистрибутивы Linux
```sh
mkdir -p ~/.local/opt/vysh
tar -xzf vysh-<версия>-linux-x64.tar.gz -C ~/.local/opt/vysh
~/.local/opt/vysh/vysh
```
Требуются библиотеки `libgtk-3` и `libsecret-1`; в дистрибутивах с графическим окружением они, как правило, уже установлены.

### Android
1. Скачайте APK со страницы [релизов](../../releases/latest): `arm64-v8a` подходит для большинства устройств, `armeabi-v7a` для старых 32-битных.
2. Установите файл, разрешив установку из этого источника.

Новая версия устанавливается поверх предыдущей; хосты и пароли сохраняются.

### Обновление
Для Windows и архива Linux удалите папку с предыдущей версией и распакуйте новую. Хосты, настройки и пароли хранятся отдельно от программы и не затрагиваются.

## Хранение данных

| | Windows | Linux | Android |
|---|---|---|---|
| Хосты, настройки, `known_hosts.json` | `%APPDATA%\vysh` | `~/.config/vysh` | внутреннее хранилище приложения |
| Пароли и парольные фразы | DPAPI (привязаны к учётной записи) | Secret Service (gnome-keyring, KWallet, KeePassXC) | Android Keystore |

Файлы хостов и настроек представляют собой обычный JSON без секретов: их можно хранить в git или синхронизировать, например, через Syncthing. Переменная окружения `VYSH_CONFIG_DIR` позволяет запустить vysh с отдельной папкой профиля.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Новая вкладка / быстрое подключение | `Ctrl+Shift+T` |
| Закрыть вкладку | `Ctrl+Shift+W` |
| Следующая / предыдущая вкладка | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Вкладка по номеру (1 = главная) | `Alt+1…9` |
| Новый хост | `Ctrl+Shift+N` |
| Переподключить | `Ctrl+Shift+R` |
| Панель файлов (SFTP) | `Ctrl+Shift+E` |
| Копировать / вставить | `Ctrl+Shift+C` / `Ctrl+Shift+V` |
| Настройки | `Ctrl+,` |

Все сочетания включают `Shift`, чтобы не перехватывать у терминала `Ctrl+W`, `Ctrl+R` и другие.

## Сборка из исходников

Требуется [Flutter](https://docs.flutter.dev/get-started/install) (канал stable). Для Windows дополнительно нужна Visual Studio 2022 с компонентами «Desktop development with C++» и «C++ ATL».

```sh
git clone https://github.com/vyto4ka/vysh && cd vysh
flutter pub get
flutter run -d windows   # или: -d linux
```

Релизная сборка для Windows одним скриптом:
```powershell
powershell -ExecutionPolicy Bypass -File tools\build-windows.ps1
# результат: dist\vysh-<версия>-windows-x64.zip
```

Для Linux дополнительно нужны пакеты `ninja-build libgtk-3-dev libsecret-1-dev`; сборка: `flutter build linux --release`.

Для Android требуется Android SDK (устанавливается вместе с Android Studio):
```sh
flutter run -d <устройство>    # отладка
./tools/build_local.sh apk     # APK по архитектурам в build/app/outputs/flutter-apk/
```
Подпись релизного APK описана в [docs/RELEASING.md](docs/RELEASING.md#android).

Для проверки интерфейса и снятия скриншотов есть демо-стенд из пяти SSH-серверов в Docker: [tools/demo](tools/demo/README.md).

### Релизы
Сборки выполняет GitHub Actions: по тегу `vX.Y.Z` в [Releases](../../releases) публикуются архив для Windows, архив для Linux, PKGBUILD и APK, а текст релиза берётся из [CHANGELOG.md](CHANGELOG.md). Порядок выпуска описан в [docs/RELEASING.md](docs/RELEASING.md).
